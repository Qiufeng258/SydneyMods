# SydneyMods —— 悉尼同居拓展包

适用于：DoLP v0.768（goosefem_mys 0.5.11.9）＋ ModI18N 汉化。

## 安装

内含两个 mod，按顺序勾选即可：

1. `mods/SydneyFamily_v1.4.3_适配DoLP0.768.zip` —— 房子与家庭基础
2. `mods/SydneyPack_v0.1.44_适配DoLP0.768.zip` —— 悉尼同居内容

## 简介

拓展了悉尼的相关事件：与悉尼完成承诺仪式后，你们可以开始同居生活，搬进属于两个人的房子，一起过日子。

## 重要提醒

⚠️ **悉尼分娩时，请务必及时回家陪伴。**
如果临盆期间长时间不回家，悉尼会独自完成分娩并**永久离开**——这个结果是不可挽回的，请留意她的孕期状态，别错过该回家的日子。
