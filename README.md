# SydneyMods —— 悉尼同居拓展包

> 目标：为 Sydney 补上“承诺仪式后的生活”——同居、房子、日常、孩子与离别。
> 当前处于 **社区测试阶段（v0.1.44）**，欢迎实机测试并反馈。

## 这是什么

在完成与悉尼的 **神殿承诺仪式（Rite of Promise）** 之后，悉尼不再只是学校/神殿里偶尔见面的人：你可以带她搬进属于你们的房子，开始真正的同居生活。

包含两个 mod：

| 文件 | 作用 |
|---|---|
| `SydneyFamily_v1.4.3_适配DoLP0.768.zip` | 房子与家庭基础（房产、房间改造、家人行、睡眠系统） |
| `SydneyPack_v0.1.44_适配DoLP0.768.zip` | 悉尼同居内容（日常、事件、怀孕分娩、孩子、夜袭） |

## 安装

1. 装好 **ModI18N 汉化**（版本需与你使用的 fork 匹配）；
2. 两个 zip **都要勾选**，同时启用；
3. 建议先备份存档再开始测试。

**兼容性**
- 主目标 fork：DoLP v0.768（goosefem_mys 0.5.11.9）；
- 已通过静态适配检查：DoL 0.5.11.9 Lyra 1.0.0a-0815（段落/锚点/图标全部命中，实机仍在社区验证中）；
- 其它 fork 未测，如锚点不命中请反馈报错段落名。

## 内容概览（同居后能玩到什么）

### 1. 同居开启
- 完成承诺仪式后，Sydney Walk 目的地会出现「告诉悉尼，房子准备好了」；
- 答应后次日她搬进你的房子，门厅出现「悉尼的房间」等家人行。

### 2. 房子与房间
- 购买/拥有房产后，空房可改造：**育儿室**（第一间）、健身房（占位）；
- 房间状态跟档位房产走（卖房/换房规则内置）。

### 3. 日常 · 靠近悉尼
她在家时，客厅/厨房/书房/小院会随她所在房间出现「靠近悉尼」：

- **聊天 (0:15)**：家常话题，真实走原版时间与数值；
- **调情 (0:15)**：夸脸红/荤笑话/擦唇/拥抱/玩头发/戳她靠近/书架够不着等；调情会沿原版轴降低她的纯度、归零后推堕落值；
- **一起出门**（每天一次）：
  - 7-8 点 → 她说太早，亲你一下让你等会再来叫；
  - 8-18 点 → 可去 **购物中心 / 海滩 / 神殿祈祷室**（走原版事件链，数值原版）；
  - 18-23 点 → 她说太晚了，明天再去；
  - 当天已出过 → 菜单不再显示该选项。
- **22:00 洗澡**：她会说先去洗澡、约你洗完去卧室找她，亲你一下后跑开；
- 陪她期间她的房间/时间块会被“锁住”，不会聊着聊着瞬移到别的房间。

### 4. 睡觉与夜袭
- 她在家时（平时 20:00 后回家、次日 6:00 前都在家；周六与孕期/产假全天在家），**你选择「睡 3 小时以上」时**，入睡前会判定一次（同一夜一次）她会不会钻进来；
- 判定命中：**这一觉只睡一半**（睡 3 小时 → 先睡 1.5 小时），随后夜袭事件把你弄醒——时间与疲劳都只按实际睡到的那 1.5 小时结算；判定没中则照常睡满；
- 时间窗口 **18:00 - 次日 05:00**（清晨 6 点是她起床做早饭的钟点）；「随便睡睡」和只睡 1-2 小时不判定；
- 选项：**搂住再睡 / 亲她一下**；亲她后可「更进一步」，进入她主导的专属做爱链（纯/堕文本分版）；
- 夜袭后她会留在你床上睡到**早上 6:00**，期间床页显示“抱着悉尼睡 N 小时”，同床有原版恢复加成；6:00 一到她起床去厨房做早饭（早餐事件）；
- 育儿室夜间也有守卫：她睡着时点宝宝只会提示“别打扰”。

### 5. 怀孕 · 分娩 · 孩子
- 同居后可以开启怀孕线：报喜（同居/未同居两条路线）、孕期全天在家、孕吐、孕期早餐与孕态性爱；
- 临盆时她会破水：可选择**叫医生上门**或**自己接生**，之后登记孩子、进育儿室；
- 育儿室支持多孩：动态婴儿床数量、每个孩子有名字/外观行，可 **抱 / 喂 / 哄睡 / 看**。

## 重要提醒（请一定看）

⚠️ **悉尼分娩期间，请务必及时回家陪伴。**
如果临盆时长时间不回家，悉尼会独自完成分娩，并**永久离开**——此结果不可挽回。请多留意她的孕期进度，别错过该回家的时间。

## 触发快速指南（测试路线）

1. 完成神殿承诺仪式；
2. 之后在 Sydney Walk 触发「告诉悉尼，房子准备好了」→ 次日搬入；
3. 入住后晚间去客厅/厨房/书房/小院找她（20-22 点菜单内容最全）；
4. 白天（周六/孕期待家时）试试「一起出门」；
5. 晚上（18:00-次日 05:00）、她在家的时段去床上**选「睡 3 小时以上」**，多试几夜就会遇到夜袭（命中会先睡一半再被打断）；
6. 孕期阶段留意临盆提示，**别缺席**。

## v0.1.44（社区测试版）修复记录

- 修复：Temple 等原版段落中的 `SydneyPack.*` 调用全部加全局守卫，避免开局直接落在 Temple 时抛 `ReferenceError: SydneyPack is not defined`；
- 修复：性奋显示 `number NaN`——做爱段落对 `nnpcArousalMult` 的乘法已加默认值守卫，并新增页面级 NaN 自愈（arousal / enemyarousal / enemyarousalmax 等异常值自动修回安全值），旧档也可恢复；
- 顺带修复了打包时的一处 JSON 转义问题（重新打包覆盖）；
- 修复：夜袭后「她睡在你床上」的期限 bug——若夜袭是在早上 6 点这次醒来触发的（睡整晚 6 点醒），旧逻辑把期限算成"到次日 6 点"，她会赖在你床上整整一天，而 6 点的厨房早餐事件（她在厨房做早饭）照常触发，两边状态打架。现在 6 点这一小时不再进入"睡你床上"状态（她直接做早饭/走正常日程），该状态也只在 18:00–次日 06:00 有效、早上 6 点一到必清，旧档自动自愈。
- 调整：**起床钟点改为 6:00 整（原先会被拖到 6:59）**——① 夜袭触发窗口由「18 点后 / 6 点前」收窄为 **18:00 - 次日 05:00**，6 点这一小时不再触发"她钻被窝"；② 新增「她在家」门禁：平时她 20:00 后才回家，所以平时 18-20 点点不出夜袭，**周六与孕期/产假全天在家时**才会从 18:00 开始；③ 早上 6:00 整清「睡你床上」标记、转厨房标记（早餐事件），且 6:00-6:59 早饭优先于当晚"提前睡下 / 沙发睡着 / 还在洗澡"等残留状态。
- 调整：**夜袭改为「睡眠打断式」**——原来是她趁你睡着钻进来、你醒来才发现；现在改成：她在家 + 时间在 18:00-次日 05:00 + 你**选择睡 3 小时以上**时，入睡前先判定一次（同一夜一次、爱意≥30、性奋≥15、40%）。命中就**只睡所选的 1/2**（3h→1.5h），随后被夜袭弄醒——时间与疲劳按实际睡到的 1.5 小时结算；没命中照常睡满。被弄醒的时刻也必须还在 18:00-05:00 内（凌晨 4 点选 8 小时这种会落到大白天的组合不判定）；**「随便睡睡」与 ≤2 小时的选择不判定**。
